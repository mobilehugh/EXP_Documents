.*Programme Comments*
* *Administration*: Everything an bureaucrat needs.
* *Adviser*: Classrooms, theatre, posters, sales.
* *Appraisals*: Cameras, tables, storage.
* *Banking*: From vaults to vouchers.
* *Library*: Physical books and research.
* *Book Reader*: Port for Little Golden Books.
* *Hotelier*: Temporary residence 1-20.
* *Combat Control*: HQ maps, comms, monitors.
* *Confection*: Retail store for small items.
* *Culinary*: Restaurant 1-10 tables.
* *Construction*: Design build items, not a factory.
* *Decoder*: Code breaker, Tutte Box, locksmith, languages.
* *Detector*: Probes, sampler, laboratory.
* *Diplomacy*: Lying that sounds like caring in many languages.
* *Entertainment*: Physical and virtual entertainment elements.
* *Etiquette*: Interstellar etiquette languages and irritation.
* *History*: Knows milieu and stores historical artifacts.
* *Industrial*: Operates a factory of some sort.
* *Law*: Docket, courtroom.
* *Mapping*: Maps everything, paper to 3d projections.
* *Mechanical*: All the tools to be a mechanic.
* *Medical*: All the tools to be a veterinarian.
* *Navigation*: Finds paths. Distance not an object.
* *Printer*: Dot matrix printer (roll again).
* *Robot*: Integrated RP robot.
* *STEP*: Ignore organic life form safety (STEP MOM)
* *Transport*: Can operate vehicles, does not have one.
* *Weapons*: Can operate weapons, does not have one.
