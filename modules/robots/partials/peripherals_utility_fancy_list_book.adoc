.Peripheral Descriptions
* *Vocation Computer* - From xref:hardware:devices.adoc#_computers[Computers,window=_blank, rel="noopener noreferrer"].
* *Cybernetic Part* - See xref:mutations:phenomics.adoc#_mechanical_insertion[Mechanical insertion,window=_blank, rel="noopener noreferrer"]. No defects.
* *Vocation* - Pursue a xref:vocations:a_introduction.adoc[Vocation,window=_blank, rel="noopener noreferrer"].
* *Damage Analysis* - Like Mechanic level equal to INT score.
* *Detect Ammunition* - 1 km per point of AWE range.
* *Detect Mutations* - 1 hex per point of AWE range.
* *Detect Pharma* - 1 km per point of AWE range.
* *Detectors* - From xref:hardware:devices.adoc#_detectors[Detectors,window=_blank, rel="noopener noreferrer"].
* *Exatmo Hardened* - Atmosphere agnostic
* *Heightened CF* - Double Control Factor
* *Identify Alien* - 2% per INT times INT_P
* *Identify Pharma* - 2% per INT times INT_P
* *Identify Value* - 2% per INT times INT_P
* *Identify Wate* - 2% per INT times INT_P
* *Identify Weapons* - 2% per INT times INT_P
* *Increase Speed* - Increase Move 2-5 times (1d4 + 1)
* *Increase WA* - 2-7 times (1d6 + 1) wate allowance
* *Languages* - Like a xref:robots:series_social.adoc[Social Robot,window=_blank, rel="noopener noreferrer"]
* *Medical Device* - See xref:hardware:biorepair.adoc[Vet Equipment,window=_blank, rel="noopener noreferrer"]
* *Psionic Mutation* - Consult xref:mutations:psionics.adoc[Psionic Mutations,window=_blank, rel="noopener noreferrer"]. No defect.
* *Miscellaneous Device* - From xref:hardware:devices.adoc[Misc. Equipment,window=_blank, rel="noopener noreferrer"].
* *Multi-bot* - Combine two bots.
* *Navigation* - Replace navigator on land, sea and stars.
* *Pharmaceutical Effect* - See xref:hardware:pharma.adoc[Pharma,window=_blank, rel="noopener noreferrer"]
* *Phenomic Mutation* - See xref:mutations:phenomics.adoc[Phenomic Mutations,window=_blank, rel="noopener noreferrer"]. No defects.
* *Robotic Override* - Control other robots.
* *Robotic Drone* - Control a smaller robot of any type.
* *Instant Acceleration* - Deadly Ramming
