.*Task Descriptions*
* *Assassinate*: Requires total surprise. Successful attack roll. Ranged attack.
* *Blackmail*: Extract value with information. Coercive.
* *Bribery*: Jump order with value. Mutual benefit.
* *Bypass, High Tech*: Find security weakness. Tech level 20 and up.
* *Bypass, Higher Tech*: Find security weakness. Tech level 15-19.
* *Bypass, Low Tech*: Get past security measures. Less than tech level 10.
* *Bypass, Mundane*: Get past security measures. Tech level 10-14.
* *Bypass, Secure*: Get past security measures. Tech level 15-19.
* *Case, High Tech*: Find security weakness. Tech level 20 and up.
* *Case, Higher Tech*: Find security weakness. Tech level 15-19.
* *Case, Low Tech*: Find security weakness. Less than tech level 10.
* *Case, Mundane*: Find security weakness. Tech level 10-14.
* *Case, Secure*: Find security weakness in secure facility.
* *Climb*: Find a way to climb something not obviously climbable.
* *Decrypt, High Tech*: Read encrypted data tech level 20 and up.
* *Decrypt, Low Tech*: Read encrypted data in low tech (<10).
* *Decrypt, Normal*: Read encrypted data in normal tech enviro (10).
* *Decrypt, Secret*: Read encrypted data tech professionally encrypted.
* *Decrypt, Secure*: Read encrypted data in secure or higher tech (11-19).
* *Disguise, Close*: Hiding appearance from friends.
* *Disguise, Family*: Hiding appearance from family, expedition members.
* *Disguise, Fast*: Temporary improvised hiding of appearance from strangers.
* *Disguise, Known*: Hiding appearance from folks that know the persona.
* *Disguise, Planned*: Careful planned hiding of appearance from strangers.
* *Disguise, Self*: Hiding appearance from self.
* *Encrypt*: Make data hard to read for others.
* *Escape!*: Out of frying pan into fire.
* *Forgery, High Tech*: Create fake document in tech level 11-19.
* *Forgery, Low Tech*: Create fake document in tech level <9.
* *Forgery, Normal*: Create fake document in tech level 10.
* *Forgery, Secure*: Create fake document in tech level >20.
* *Incapacitate*: Requires total surprise. Successful attack roll. Ranged attack.
* *Interrogation*: Get info from anthro using pressure.
* *Lying*: Falsification without tells.
* *No Guilt*: Expunge guilty feelings.
* *Pilfer*: Sleight of hand conceal hand sized thing.
* *Sneak, Combat*: Move self around without being noticed in during combat.
* *Sneak, In Crowd*: Move self around without being noticed in a crowd.
* *Sneak, Security*: Move self around without being noticed in secure situation.
* *Sneak, Standard*: Move self around without being noticed.
* *Stun, Combat*: Successful attack roll.
* *Stun, surprise*: Total surprise. Successful attack roll.
* *Trap*: Set trap to activate alarm or attack.
